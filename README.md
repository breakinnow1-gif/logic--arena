# 논리 아레나

초등 6학년을 위한 **수능형 논리 문항 1:1 대결 · 클래스 랭크 리그**입니다.
GitHub Pages(무료 웹 호스팅)에 올리고, 선생님 본인의 Firebase(무료 저장소)에 연결해 씁니다.

## 무엇을 할 수 있나요

- **선생님(master)**: 학생 등록, 문항 관리(직접 입력·JSON 가져오기/내보내기), 1:1 매치 배정(직접 짝 / 실력 비슷한 친구끼리 / 무작위), 실시간 관전, 순위표, 경기 기록, 새 시즌(점수 초기화), 학생 접속 링크·QR 코드
- **학생**: 배정된 대결 입장, 같은 문항을 동시에 풀고 문항마다 정답·해설 확인, 결과에 따라 점수(Elo) 변동, 등급 배지, 연습 모드, 지난 경기 다시 보기
- **점수 규칙**: 정답 100점 + 빨리 맞힐수록 최대 50점 보너스. 총점이 높은 쪽이 승리. 모든 학생은 1000점에서 시작하고, 강한 상대를 이기면 많이 오릅니다.
- **기본 문항 22개**: 삼단논법, 대우, 필요·충분조건, 참·거짓 추리, 조건 배치, 숨은 전제, 오류 찾기, 강화·약화, 논증 구조, 논쟁 분석, 경제(수요·공급) 추론, 자료 해석

## 1단계 — GitHub Pages에 올리기 (약 5분)

1. [github.com](https://github.com)에 로그인하고 오른쪽 위 **＋ → New repository**를 누릅니다.
2. 이름을 적고(예: `logic-arena`) **Public**으로 둔 채 **Create repository**를 누릅니다.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누르고, 이 폴더의 파일을 모두 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
   - `index.html`, `style.css`, `app.js`, `store.js`, `questions.js`, `rules.js` (필수)
   - `firestore.rules`, `README.md` (참고용)
4. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 정하고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://내아이디.github.io/logic-arena/` 주소가 생깁니다.

## 2단계 — Firebase 연결하기 (약 10분)

사이트를 열고 **선생님: 우리 반 처음 설정하기**를 누르면 화면 안내가 단계별로 나옵니다. 요약하면:

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트 만들기
2. **Authentication → 로그인 방법 → 이메일/비밀번호** 사용 설정
3. **Firestore Database** 만들기 (위치: `asia-northeast3` 서울, 프로덕션 모드)
4. Firestore **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 **게시**
5. **프로젝트 설정 → 내 앱 → 웹(</>)** 앱 등록 후 `firebaseConfig` 코드를 사이트에 붙여 넣기
6. 반 이름과 선생님 비밀번호를 정하면 끝 (아이디는 `master`)

설정이 끝나면 **설정 탭의 접속 링크나 QR 코드**를 학생들에게 나눠 주세요. 학생은 한 번만 그 링크로 들어오면 됩니다.

> 연결 전에 **설정 없이 데모로 체험하기**로 미리 써 볼 수 있어요. 데모 데이터는 그 브라우저에만 저장되고, 새 탭에서 다른 학생으로 로그인하면 1:1 대결을 시험할 수 있습니다.
> 데모 계정: 선생님 `master` / `123456`, 학생 `s1`~`s6` / `123456`

## 수업에서 쓰는 순서

1. **학생 관리**에서 학생 추가 (엑셀에서 `번호 이름 아이디 비밀번호` 네 칸을 복사해 한꺼번에 붙여 넣기 가능)
2. **매치 배정**에서 문항 수·제한 시간·유형·난이도를 고르고 짝 배정
3. 학생 화면에 「대결이 배정됐어요!」 카드가 뜨면 **입장하기** → 두 사람이 모두 들어오면 자동 시작
4. **실시간 경기**에서 관전하거나, 한 명이 들어오지 못하면 **바로 시작** / **취소**

## 문항 만들기 팁

- 문항은 **지문 / 발문 / <보기> / 선지 5개 / 정답 / 해설**로 이루어집니다. 지문과 <보기>는 비워 둬도 됩니다.
- 해설은 대결 중 각 문항 채점 때와 다시 보기에서 학생에게 보입니다. 오답 선지가 왜 틀렸는지까지 적어 주면 복습 효과가 큽니다.
- **내보내기(JSON)**로 받은 파일을 다른 반 선생님이 **가져오기(JSON)**로 넣으면 문항을 나눌 수 있어요.
- 정답 번호가 한쪽에 몰리지 않도록 선지 순서를 골고루 배치하세요. (기본 22문항은 ①~⑤가 3·5·5·5·4개로 나뉘어 있어요.)

## 알아 두면 좋은 점

- **비밀번호 변경·학생 삭제 후 같은 아이디 재사용**: 웹에서는 다른 사람의 로그인 계정을 지울 수 없어요. Firebase 콘솔 → Authentication에서 `아이디@arena.class` 계정을 지운 뒤 다시 추가하세요.
- **정답 데이터**: 학생 기기도 문항 데이터를 내려받기 때문에, 개발자 도구를 다룰 줄 아는 학생은 이론상 정답을 볼 수 있어요. 성적 평가가 아닌 수업 활동용으로 쓰는 것을 권합니다.
- **반이 여러 개라면**: 반마다 Firebase 프로젝트를 하나씩 만들면 같은 사이트 주소로 반별 접속 링크를 따로 쓸 수 있어요.
- **무료 사용량**: 한 반(30명 내외)이 수업 시간에 쓰는 정도는 Firebase 무료 요금제(Spark) 범위 안입니다.
